# LP — FR Bueno Municipal

Landing page do empreendimento **FR Bueno Municipal** (FR Incorporadora), Setor Bueno, Goiânia — Av. T-9 com T-28.

- Página estática: `index.html` (HTML/CSS/JS em arquivo único)
- Imagens: `images/`
- Fontes: Space Grotesk + Instrument Serif (Google Fonts)
- Paleta: creme `#FBFAF3` · marrom `#211E1B` · dourado `#E7BC84` · profundo `#240F10`

Desenvolvido por **3ADS**.
