# LP — FR DGN (Distrito Goiás Norte)

Landing page do empreendimento **FR DGN** (FR Incorporadora + WA Participações), Setor Criméia Oeste, Goiânia.

- Página estática: `index.html` (HTML/CSS/JS em arquivo único, com lightbox nas plantas e na galeria)
- Imagens: `images/`
- Fontes: Space Grotesk + Montserrat (Google Fonts)
- Paleta: rosa `#FFEFF2` · coral `#F55E45` · lima `#DEE575` · profundo `#240F10`

Desenvolvido por **3ADS**.
