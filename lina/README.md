# LP — Lina Praça do Sol

Landing page do empreendimento **Lina Praça do Sol** (FR Incorporadora), Setor Oeste, Goiânia.

- Página estática: `index.html` (HTML/CSS/JS em arquivo único)
- Imagens: `images/`
- Fonte: Manrope (Google Fonts)

Desenvolvido por **3ADS**.
